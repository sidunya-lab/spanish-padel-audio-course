# Стартовый запрос для Gemini

Как пользоваться: открой новый чат в Gemini, приложи файлы `TZ.md`, `content/course_text_2026-10-15.md`, `examples/test_chapter.dsl.txt`, `examples/live_speech_lines.md`, сценарий нужной главы из `scripts_2026-11-02/` и аудио `reference_audio/test_chapter_approved.mp3`, затем вставь текст ниже.

Обычный чат Gemini подходит для написания сценариев. Для записи со строго заданными паузами нужен программный монтаж: Gemini API или Google AI Studio плюс Python и ffmpeg (раздел 10 ТЗ).

---

## Запрос 1. Сценарий главы

```
Ты — методист и сценарист аудиокурса испанского языка для русскоязычного игрока в падел.

Во вложении:
- TZ.md — техническое задание. Соблюдай его полностью, особенно разделы 5 (структура главы и правила текста) и 6 (формат сценария).
- course_text_2026-10-15.md — содержание 24 глав: цель, логика, фразы, диалог.
- test_chapter.dsl.txt и live_speech_lines.md — образцы готовых строк сценария.
- chNN.txt из папки scripts_2026-11-02 — сценарий этой главы в версии от 2 ноября 2026 года, восстановленный по аудио. Бери его за основу и улучшай, а не пиши с нуля.
- test_chapter_approved.mp3 — эталон звучания.

Задача: напиши сценарий главы [НОМЕР И НАЗВАНИЕ] в формате из раздела 6 ТЗ.

Требования:
1. Один файл, одна строка — один элемент: N, T, G, D, L, P, S, V, E.
2. Диалог: 4–6 реплик, голоса A и B, испанский Испании.
3. Логика: 1–3 коротких абзаца, испанские слова в фигурных скобках.
4. 6–8 основных фраз по 3–8 слов. К каждой — русский смысл в виде ситуации и короткое пояснение.
5. 2–4 задания на самостоятельный ответ.
6. 1–2 строки «Живая речь»: 12–20 слов, естественная разговорная речь, только знакомая лексика плюс 2–3 разговорных слова.
7. Обращение на «ты». Запрещены формулы «Следующая фраза», «Слушайте», «Скажите по-испански», «По-испански так». Ни одна служебная фраза не повторяется больше двух раз.
8. Числа и годы пиши словами. Русский фрагмент между испанскими вставками — не короче двух-трёх слов.
9. Факты о реальных людях и клубах — только из приложенных материалов. Ничего не добавляй от себя.
10. Расчётная длительность главы — 4–7 минут.

После сценария дай короткий список: что ты изменил по сравнению с приложенным сценарием и октябрьским текстом и почему.
```

## Запрос 2. Программа сборки

```
Во вложении TZ.md и пример сценария test_chapter.dsl.txt.

Напиши программу на Python, которая превращает сценарий главы в MP3 по разделам 5–11 ТЗ:

1. Разбор сценария в последовательность фрагментов (язык, голос, темп, текст, пауза после), включая разбор фраз с конца и автоматические возвраты к пройденным фразам.
2. Синтез каждого фрагмента отдельным запросом. Русский — Gemini TTS, голос Charon. Испанский — два голоса с акцентом Испании, мужской A и женский B; модель и голоса вынеси в настройки.
3. Темп испанского: обычный, −10 % для слов внутри объяснения, −15 % для фразы целиком перед финальным повтором, −35 % для кусков разбора.
4. Кэш фрагментов по хэшу от текста, голоса и темпа.
5. Проверка каждого русского фрагмента распознаванием речи, до трёх перезаписей, список сомнительных фрагментов в отчёт.
6. Монтаж через ffmpeg: обрезка тишины по краям (порог −45 дБ), паузы строго по разделу 8 ТЗ, громкость −16 LUFS с пиком не выше −1,5 дБ, MP3 128 кбит/с, моно.
7. Сборка комплекта: главы по отдельности, общий MP3, ZIP, оглавление с таймкодами.

Сначала собери только тестовую главу и покажи результат. Весь курс — после одобрения.
```

## Запрос 3. Проверка готовой главы

```
Во вложении TZ.md, сценарий главы и готовый MP3.

Проверь запись по разделу 11 ТЗ:
1. Все ли строки сценария прозвучали, нет ли пропусков и дублей.
2. Правильны ли русские ударения; отдельно выпиши слова с двойным ударением.
3. Нет ли запрещённых формул и повторов служебных фраз чаще двух раз.
4. Соответствуют ли паузы разделу 8 и нет ли тишины длиннее 2 секунд, кроме пауз на задание-ситуацию (около 2,5 секунды).
5. Звучат ли испанские слова испанским голосом с акцентом Испании.

Ответ дай списком замечаний с таймкодами.
```
